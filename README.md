
# Dustin Morris - Personal Portfolio Website

This is my final project for Web Development (Spring 2025). The goal of this assignment was to create a fully functional, professional 7 page personal website using valid HTML and CSS (with Bootstrap).

Project Structure

The site consists of the following pages:

- `index.html` – Home
- `about.html` – About Me
- `experience.html` – Work Experience and Skills
- `certifications.html` – Certification Showcase
- `education.html` – Academic History and Coursework
- `downloads.html` – Study Guides, Cheat Sheets, and IT Resources
- `contact.html` – Contact Info (email, phone, LinkedIn)

Features

- Responsive layout using Bootstrap 5
- Clean, professional color scheme (black, gold, white)
- Graduation photo and professional headshot
- Structured education table with course history
- Stylized Downloads page with categorized resources
- Resume download link included in `experience.html`
